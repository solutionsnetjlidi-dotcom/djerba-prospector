# 🎯 Djerba Prospector — OMARSOFT

Outil de prospection commerciale pour identifier et suivre les établissements de l'île de Djerba sans site web.

Développé par **Omar Jlidi** — [Jlidi Network Solutions / OMARSOFT](mailto:contact@omarsoft.tn)

## 🚀 Lancer en local

```bash
npm install
npm run dev
```
→ Ouvre http://localhost:5173

## 📦 Build de production

```bash
npm run build
```

## 🌐 Déploiement

Ce projet se déploie automatiquement sur **GitHub Pages** à chaque push sur `main`
via le workflow `.github/workflows/deploy.yml`.

URL de production : `https://<ton-username>.github.io/djerba-prospector/`

## 🛠️ Stack

- React 18
- Vite 5
- GitHub Actions (CI/CD)
- GitHub Pages (hébergement gratuit)
